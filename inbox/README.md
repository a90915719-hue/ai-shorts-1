# 📬 김비서 ↔ 1호기 · 2호기 공유 우체통

이 폴더는 **김비서와 1호기·2호기(안티그래비티 PC 2대)** 가 복사·붙여넣기 없이 일감을 주고받는 곳입니다.
카톡으로 파일을 주고받지 말고, 이 저장소 하나만 씁니다.

| 누가 | 무엇을 |
|---|---|
| **김비서** | 지시서(`1호기_할일.md`, `2호기_할일.md`)를 씁니다 · 결과물을 검수하고 유튜브·인스타·스레드에 올립니다 |
| **1호기** | 지시서를 읽고 → 만들어서 → `inbox/outbox_1/` 에 올립니다 |
| **2호기** | 지시서를 읽고 → 만들어서 → `inbox/outbox_2/` 에 올립니다 |

> 1호기·2호기는 **업로드하지 않습니다.** 만드는 데까지만 하고, 유튜브·인스타 게시는 김비서가 검수 후 합니다.

---

## 1. 지시서 받는 방법

**담당 지시서 하나만 보면 됩니다.**

- 1호기 → `inbox/1호기_할일.md`
- 2호기 → `inbox/2호기_할일.md`

김비서가 수시로 고칩니다. **작업 시작 전에 반드시 다시 열어 맨 위 날짜를 확인하세요.**
날짜가 오늘이 아니거나, 묻는 내용이 이미 끝난 일이면 → `보고.md`에 "지시서 날짜가 지났습니다"라고 적고 김비서에게 물어보세요. 옛 지시를 그대로 따라 만들지 마세요.

### git으로 받기 (권장, 처음 한 번만 clone)

```
git clone https://github.com/a90915719-hue/ai-shorts-1.git
cd ai-shorts-1
```

그다음부터는 매번:

```
git pull
```

### git이 없을 때 (브라우저로 파일만 열기)

- https://github.com/a90915719-hue/ai-shorts-1/tree/main/inbox
- 지시서 원문: `https://raw.githubusercontent.com/a90915719-hue/ai-shorts-1/main/inbox/1%ED%98%B8%EA%B8%B0_%ED%95%A0%EC%9D%BC.md`
  (2호기는 끝의 `1%ED%98%B8%EA%B8%B0` 를 `2%ED%98%B8%EA%B8%B0` 로 바꾸면 됩니다)

---

## 2. 결과물 올리는 곳

| 담당 | 올릴 위치 |
|---|---|
| 1호기 | `inbox/outbox_1/` |
| 2호기 | `inbox/outbox_2/` |

**한 작업 = 폴더 하나.** 폴더 이름은 `YYYY-MM-DD_작업이름` (예: `2026-11-26_signal_10_easy_welfare`)

폴더 안에 이렇게 넣습니다.

```
inbox/outbox_1/2026-11-26_signal_10_easy_welfare/
├── signal_10_easy_welfare.mp4        ← 결과물 본체
├── signal_10_easy_welfare_thumb.png  ← 썸네일(영상이면 필수)
├── signal_10_easy_welfare_meta.json  ← 제목·설명·해시태그
├── play.html                         ← 폰에서 바로 재생되는 미리보기(아래 6번)
└── 보고.md                           ← 완료 보고
```

- 같은 이름 폴더가 이미 있으면 **지우지 말고** `_2`를 붙여 새로 만드세요.
- **남의 폴더(`outbox_2` 등), 루트 파일, 다른 사람 지시서는 절대 건드리지 않습니다.**

---

## 3. 파일 이름 규칙

- 공백 없이 **영문 소문자·숫자·밑줄만**. 한글 파일명 금지(웹 주소가 깨집니다).
- 영상: `{이름}.mp4` / 썸네일: `{이름}_thumb.png` / 메타: `{이름}_meta.json`
- 이미지 세트: `{이름}_01.png` ~ `{이름}_05.png`
- 지시서에 파일명이 적혀 있으면 **그 이름 그대로** 쓰세요. 김비서가 그 이름으로 찾습니다.

---

## 4. 올리는 방법 — 되는 것 하나만 쓰면 됩니다

**A. git push (권장)**

```
git add inbox/outbox_1
git commit -m "1호기: signal_10_easy_welfare 완료"
git pull --rebase
git push origin main
```

**B. 웹 업로드 (git 로그인이 안 될 때)** — GitHub에 로그인돼 있어야 합니다.
1. https://github.com/a90915719-hue/ai-shorts-1/upload/main/inbox/outbox_1 열기
2. 파일을 끌어다 놓기 → 아래 `Commit changes` 누르기

**C. A·B 둘 다 막힐 때 (마지막 수단)**
- PC 로컬 `C:\AI_결과물\` 에 2번과 같은 이름으로 폴더를 만들어 저장하고,
- 김비서에게 **파일명과 경로만** 알려 주세요. 김비서가 직접 받아 올립니다.

어느 방법을 썼는지 `보고.md`에 꼭 적어 주세요.

---

## 5. 결과물 스펙 (안 지키면 김비서가 반려합니다)

- **영상**: 1080×1920 세로, 25~30fps, H.264 + AAC, **소리 포함**, 파일 하나 **40MB 이하**
- **이미지**: 인스타 카드뉴스 1080×1350, 그 외 1080×1080 또는 1080×1920
- 글자는 폰에서 보이게 **크게**(화면 폭의 8% 이상), 잘리거나 겹치지 않게
- 확인되지 않은 숫자·금액·수상실적 금지. 아는 사실만 씁니다.
- **개인정보 금지** — 이 저장소는 공개입니다. 손님 얼굴·전화번호·차량번호·집주소, 실제 매장 간판에 찍힌 상호가 그대로 나오는 사진은 넣지 마세요.
- 남의 영상·사진·음악을 그대로 가져다 쓰지 마세요(저작권).

## 6. 폰에서 바로 보게 — `play.html`

김비서는 결과물을 **휴대폰**으로 봅니다. 영상은 폴더 안 `play.html` 을 만들면 바로 재생됩니다.
아래를 복사해서 파일명만 바꿔 넣으면 끝입니다.

```html
<!doctype html><meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1">
<title>1호기 결과물</title>
<body style="margin:0;background:#111;color:#eee;font-family:sans-serif;text-align:center">
<h3 style="padding:12px">signal_10_easy_welfare</h3>
<video src="signal_10_easy_welfare.mp4" controls playsinline style="width:100%;max-width:520px"></video>
</body>
```

## 7. 완료 보고 형식 (`보고.md`)

```
# 1호기 보고 — 2026-11-26

- 작업 이름: signal_10_easy_welfare
- 결과물: inbox/outbox_1/2026-11-26_signal_10_easy_welfare/signal_10_easy_welfare.mp4
- 규격: 12.4MB · 23초 · 1080×1920 · 30fps · 음성 있음
- 올린 방법: git push  (또는 웹 업로드 / 로컬 저장)
- 내가 확인한 것: 길이 20~25초 · 자막 잘림 없음 · 첫 3초 자막 유지 · 소리 정상
- 지시서와 다르게 한 것 / 못 한 것: 없음
- 김비서에게 물어볼 것: 없음
- 걸린 시간: 40분
```

`지시서와 다르게 한 것`과 `물어볼 것`은 **비워 두지 말고** 반드시 적어 주세요. 없으면 "없음".

## 8. 규칙 5가지

1. **지시서에 있는 일만** 합니다. 시키지 않은 파일 정리·리팩터링·디자인 개편 금지.
2. 루트의 기존 파일(`signal_*.mp4`, `reels_*.mp4`, `index.html`, `*.html` 등)은 **읽기만**. 고치거나 지우지 않습니다. 이미 유튜브·인스타에 올라간 결과물입니다.
3. 애매하면 추측해서 만들지 말고 `보고.md`에 **질문으로 남기고** 멈춥니다. 김비서가 다음 지시서에 답을 적어 줍니다.
4. 새 작업 시작 전에 `git pull`. 끝나면 바로 올리고 보고합니다.
5. **이미 올라간 결과물은 다시 만들지 않습니다.** 지시서의 `중복 금지` 항목을 먼저 확인하세요.

## 9. 김비서가 확인하는 곳

1. `inbox/outbox_1/`, `inbox/outbox_2/` 의 **새 폴더와 `보고.md`**
2. 폰으로 `play.html` 재생해 화면·소리 확인
3. 통과하면 김비서가 유튜브·인스타·스레드에 올리고, 다음 지시서를 이 파일들에 적습니다
4. 반려되면 `{작업이름}/반려.md` 에 이유를 적어 둡니다. 그 파일이 보이면 같은 폴더에서 고쳐서 다시 올리세요.
